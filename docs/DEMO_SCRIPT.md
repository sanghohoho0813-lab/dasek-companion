# 발표용 시연 진행 안내 (`/demo`)

**주소:** 공식 URL + `/demo` (예: `https://dasek-companion-522v.vercel.app/demo`) · 고객 화면 PC 상단 '발표용 시연' 또는 DEMO 도구 → '발표용 시연 모드'

## 준비 (발표 10분 전)
1. 발표용 노트북 브라우저에서 `/demo` 열기 → 오른쪽 위 **처음부터** → 확인 (이 브라우저의 시연 데이터 초기화)
2. 화면 비율: 1440×900 이상 권장. 프로젝터 해상도가 낮으면 **운영 AX 크게 / 고객 화면 크게**로 하나씩 보여주기
3. 발표 메모는 기본으로 켜져 있음 — 청중 화면에 메모를 숨기려면 **발표 메모** 끄기
4. 키보드 → / ← 로 단계 이동

## 8단계 흐름 (약 5~7분)
| 단계 | 누를 것 | 보여줄 것 |
|---|---|---|
| 1 다색컴패니언은 무엇인가 | — | 고객 앱과 운영관리 프로그램이 같은 데이터 |
| 2 고객이 둘러봄 | — | 다색냥 실제 고양이 14마리(매장 카드 정보) + 11마리 준비 중 · 메뉴 사진 |
| 3 친구 추천으로 가입 | **시연 고객으로 가입하기** | 고객 쿠폰함에 가입 쿠폰, AX 회원에 새 회원, 추천 보상 '대기' |
| 4 매장 체크인 | **오늘의 코드로 체크인** | AX '지금 처리할 일' 대기 +1 |
| 5 직원이 한 번 눌러 확인 | **직원으로 방문 확인** (또는 오른쪽 AX 화면의 '방문 확인'을 직접 클릭) | 고객 스탬프 1/10, 추천 보상 '확정' |
| 6 성과 기록 | — | 요청→결정→승인→조치→결과 기록 |
| 7 재방문 알림 | **책임자로 승인·발송** | 고객 알림함에 알림 |
| 8 통합 웰니스 플랫폼 | — | 대표 기획안: AI 푸드 웰니스 · AI 멘탈·펫 웰니스 (확장 예정) |

## 말할 때 주의 (정직하게)
- 숫자는 모두 **DEMO 시연 데이터** — 실제 매출·회원 수가 아님
- 고양이 25마리 중 **14마리는 매장 카드 기준 실제 정보**, 11마리는 준비 중 · 메뉴 사진은 아직 샘플
- 추천은 지금 **규칙 기반**(AI API 미연동) — AI 추천·영양 기록·성향 분석은 **확장 예정**
- 결제·구독·외부 연동은 아직 없음
